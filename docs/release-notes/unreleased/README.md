# Unreleased Changes

These changes are merged into `master` but are not part of a release yet. Each file in this folder
describes one pull request, and the file name is the pull request number.

To use them before the next release, [build Polar from source](../../../CONTRIBUTING.md).

When a release is prepared, these files move into [CHANGELOG.md](../../../CHANGELOG.md). To add one,
see [how to write a release note](../README.md).
