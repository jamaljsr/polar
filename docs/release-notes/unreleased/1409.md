# Features

- Show when an LND node's wallet is locked, for nodes started without the `--noseedbackup` flag ([#1376](https://github.com/jamaljsr/polar/pull/1376))
- Create and unlock an LND wallet from inside Polar ([#1384](https://github.com/jamaljsr/polar/pull/1384))
- Restore an LND wallet from its seed phrase, with an optional channel backup file ([#1393](https://github.com/jamaljsr/polar/pull/1393))
- Run Core Lightning nodes on Windows ([#1369](https://github.com/jamaljsr/polar/pull/1369))
- Add optional memo and expiry fields when creating an invoice ([#1368](https://github.com/jamaljsr/polar/pull/1368))
